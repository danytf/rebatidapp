⛶ Modo lectura
❓ Cómo usar la app
  • 🔍
    Buscador
    Busca por palabra clave en preguntas y respuestas.
  • 🏢
    Entidad
    Filtra las fichas por ONG (en el móvil con el botón "Entidad", en escritorio con la barra lateral).
  • 🗂️
    Categorías
    Toca el encabezado de cada bloque para desplegarlo o plegarlo.
  • ⚡
    Respuesta rápida / completa
    Cada ficha se abre mostrando la respuesta rápida por defecto; toca "Ver respuesta completa" si necesitas el desarrollo entero.
  • 💡
    Consejo de captación
    Dentro de cada ficha, un consejo práctico sobre cómo plantear la respuesta en la conversación; está plegado por defecto, toca para desplegarlo.
  • ⛶
    Modo lectura
    Abre una ficha a pantalla completa, ideal para leerla tranquilo antes de hablar con alguien.
  • ☆
    Favoritos
    Marca las fichas que más uses para tenerlas siempre a mano.
  • 🎯
    Modo ensayo
    Practica sin ver la respuesta y comprueba tu progreso entre partidas.
  • ➕
    Añadir / Modificar
    Propón una objeción nueva o un cambio sobre una ficha existente; se manda por email a formación.
  • ☀️
    Tema
    Cambia entre claro y oscuro.
